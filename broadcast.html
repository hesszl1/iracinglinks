BROADCASTING

Software and tools for broadcasting races.

Website Description
Open Broadcaster Software (OBS) A free, open source, and highly customizable program for streaming and recording.
ATVO Highly customizable timing and ticker software for broadcasts. Not recommended for beginners.
SDK Gaming A much more approachable alternative to ATVO. Less flexible in terms of customizability.
iRacing-TV An alternative to both SDK and ATVO for broadcast overlays.
