iRacing Links

INFORMATION

Stats, insights, etc. not normally visible in the iRacing UI.

Website Description
iRacing Insights Compiles stats and insights for a driver.
iRacing Reports Provides stats and analysis of official iRacing series results.
iRacing Survey Provides stats for participation and strength of official series.
SeasonStandings In-depth analysis and projections of both the current iRacing season and previous ones.
Word On The Street
(WOTS)		 A crowdsourced driver tagging and reputation system that provides a local API to communicate with overlays and other apps.
Saturday's Spinout Web-based tool useful for viewing race history, note-taking, and analytics functionality.
iRacer's Resource Displays iRacing links.
Sim Racing
Liquipedia		 A database of sim racing e-sports records and events, similar to Wikipedia.
If you're familiar with Counter-Strike Liquipedia, this runs off the same website.
